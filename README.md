# Hue

Hue is a color picker built as a single HTML file with no external libraries. It has a homepage and a picker page, where you can drag to choose a color, type a value, or sample one from your screen, then copy it as HEX, RGB or HSL. It also shows contrast against white and black, suggests related colors, and lets you save a small palette that stays in your browser.

Click this link to view the project: https://its-nihad.github.io/color-picker/

To run it yourself, download `index.html` and open it in any modern browser. To host it, put the file in a GitHub repository and turn on GitHub Pages.
